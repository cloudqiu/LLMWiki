## 名称与版本

- 收件箱与 PyPI 发布名：`pip`；Python import 名不适用（命令行用法）。
- [PyPI 项目发布页](https://pypi.org/project/pip/)；查阅日期 2026-11-01；页面显示版本：26.2.2。目标项目须以 requirements/lock 文件核对实际安装版本。

## 用途

安装和管理 Python 包的命令行工具。

## 典型入口

```bash
python -m pip install requests
```

以上为按项目发布页与公开 API 整理的最小片段；需满足安装、外部服务或运行环境条件；未在本机运行。

## 身份与边界

- PyPI 维护者账号或发布者不能单独证明创建者及完整当前维护团队；两者待验证。
- 通常作为命令行工具调用，不建议依赖其非公开 Python 内部 API。
