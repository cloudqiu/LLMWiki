# der

## 用途与适用场景

官方摘要为“Pure Rust embedded-friendly implementation of the Distinguished Encoding Rules (DER) for Abstract Syntax Notation One (ASN.1) as described in ITU X.690 with full support for heapless `no_std`/`no_alloc` targets”。此页记录版本与来源；具体选用场景待核实。（[[der-rust-official-research]]）
