# github.com/golangci/misspell

## 用途与适用场景

检查英文拼写错误。（[[golangci-misspell-go-official-research]]）

## 依赖与版本

- Go 模块：`github.com/golangci/misspell`；在项目中执行 `go get github.com/golangci/misspell`。
- 官方资料查阅日期：2026-11-01；具体版本由项目锁定。

## 作者与维护者

- 官方仓库归属账号：[[golangci]]；这只确认账号关联。
- 具体创建者与当前维护者待验证。

## 典型用法

以下是对照官方仓库资料整理的最小片段，**尚未在本机运行**。Go 片段需要补齐 import、变量或外围函数。

```sh
misspell README.md
```

## 关键限制

- 自动修复需另加 -w；不要对非英文文本盲目运行。
