# 命令提示符（CMD）

## 简介

Windows 的传统命令行解释器（`cmd.exe`），原文定位为「Windows 的老命令行，跑 `.bat` 脚本和基础操作」（原文 L18）。代表性的基础命令：`dir`、`ipconfig`（原文 L118）。

## 关键事实

- 在 [[windows-terminal]] 中作为一个可开标签的 shell 存在（下拉箭头 → 命令提示符）。
- 其原生窗口即是「白字黑底、复制粘贴别扭」的旧观感来源——[[windows-terminal]] 想替换的正是这层外壳（原文 L26）。
- 与 [[powershell]] 的关系（并存 / 后继）、哪些场景仍必须用 CMD——**待补充**（原文未展开）。

## 在本库中的角色

- 「三世界命令」中最保守的一支：AI 给的命令里出现 `.bat`、`dir`、`ipconfig` 时属于此界（原文 L118）。
