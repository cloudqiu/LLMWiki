# pem-rfc7468

## 用途与适用场景

官方摘要为“PEM Encoding (RFC 7468) for PKIX, PKCS, and CMS Structures, implementing a strict subset of the original Privacy-Enhanced Mail encoding intended specifically for use with cryptographic keys, certificates, and other messages. Provides a no_std-friendly, constant-time implementation suitable for use with cryptographic private keys.”。此页记录版本与来源；具体选用场景待核实。（[[pem-rfc7468-rust-official-research]]）
