# github.com/golangci/golangci-lint/v2

## 用途与适用场景

聚合多种 Go linter 并统一配置、运行，适合项目和 CI。（[[golangci-lint-v2-go-official-research]]）

## 依赖与版本

- 官方模块：`github.com/golangci/golangci-lint/v2`。
- 安装或依赖声明：`go install github.com/golangci/golangci-lint/v2/cmd/golangci-lint@v2.15.0`。
- 查阅日期：2026-11-01；具体版本以目标项目锁定为准。

## 作者与维护者

- golangci 组织发布；最初创建者及当前具体维护人员待验证。

## 典型用法

下面示例以官方文档或项目 README 为依据；**未在本机运行**。命令需在适当 Go 项目中执行；Go 代码片段需补齐 import 与外围函数。

```sh
golangci-lint run
```

## 关键限制

- v2 配置与 v1 不完全兼容；升级须核对迁移文档。
